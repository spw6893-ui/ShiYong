# 拾用：AI 效率内容产品规格（草稿版）

**版本**：0.1  
**日期**：2026-08-09  
**状态**：MVP 原始规划；任务分类已由 `docs/content-taxonomy.md` 更新
**需求质量评分**：84/100

> 本文将“拾用”重新聚焦为一个专门帮助普通人用 AI 提升学习、工作和内容处理效率的网站。本文先确定产品方向、内容结构和 MVP，暂不进入完整技术实现。

## 1. 产品定位

### 一句话定位

**拾用帮助普通人找到真正能提高效率的 AI 方法、工作流和工具。**

### 核心承诺

- 不做 AI 新闻聚合，不追模型参数和行业口号。
- 不堆几百个工具链接，只推荐经过筛选、能解决具体问题的工具。
- 每篇内容都回答三个问题：解决什么问题、怎么操作、有什么限制。
- 用户应当能在 10 分钟内找到一个今天就能尝试的方法。

### 推荐品牌文案

- 品牌名：**拾用**
- 主标题：**让 AI 真正帮你省时间**
- 副标题：**筛选实用方法、工作流和工具，把 AI 用进每天的学习与工作。**
- 口号：**少看一点资讯，多完成一点事情。**

### MVP 产品形态

MVP 采用“**每周总结 + 可筛选资料库**”的双核心结构：

- 每周总结负责告诉用户这周先看什么，降低选择成本。
- 资料库负责长期沉淀方法、工作流、工具和汇总内容。
- 首页只负责解释产品并连接这两个入口。
- 不为每个分类创建独立栏目页，避免导航复杂和内容不足造成空页面。

## 2. 目标用户

### 主要用户

1. **普通上班族**：需要写邮件、整理会议、处理文档、制作汇报。
2. **内容创作者**：需要找选题、整理资料、写初稿、制作图片和视频。
3. **学生与自学者**：需要理解长文、整理课程、制作复习资料和学习计划。
4. **小团队与个体经营者**：需要用较低成本完成运营、客服、表格和内容工作。

### 共同痛点

- 知道 AI 有用，但不知道具体从哪里开始。
- 收藏了很多工具，实际没有形成稳定工作流。
- 不知道同类工具如何选择。
- 担心隐私、答案错误、付费限制和学习成本。
- 花在研究 AI 上的时间，比真正节省的时间更多。

## 3. 产品边界

### 重点内容

- AI 基础使用方法
- 可复制的办公与学习工作流
- 按任务选择工具的比较内容
- 小白友好的步骤教程
- 工具的免费范围、使用限制和注意事项
- 每周一次“值得尝试的 AI 效率方法”

### 明确不做

- 投资、股票、量化交易和市场资讯
- 单纯的模型新闻、参数对比和跑分榜单
- 面向专业开发者的模型训练、算法论文和 API 基建
- 低价账号、共享账号、卡密和来源不明的中转服务
- 不稳定的“无限免费 API”与临时福利
- VPN、网盘资源和破解软件
- “副业暴富”、收益承诺和批量营销灰产
- 没有实际使用场景的工具堆砌

## 4. 内容架构

网站内容不再按“AI / 投资 / 效率成长”拆成多个栏目页。MVP 只保留一个统一资料库和一个每周总结，所有内容通过筛选组织。

### 一级导航

| 导航 | 作用 | 典型内容 |
|---|---|---|
| 首页 | 说明定位并提供两个核心入口 | 本周摘要、资料库搜索、常用筛选 |
| 每周总结 | 建立周期性回访 | 本周变化、方法、工作流、工具、一个行动 |
| 资料库 | 统一承载所有长期内容 | 方法、工作流、工具、对比和汇总 |

除内容详情页外，MVP 不再创建其他一级页面。“AI 方法”“工作场景”“工具对比”和“入门内容”全部作为资料库的内容类型或筛选条件。

### 三个核心内容类型

#### A. AI 方法

帮助用户建立稳定、可迁移的 AI 使用能力，而不是记忆某个工具的按钮。

- 怎样描述背景、目标、约束和示例
- 怎样把模糊任务拆成 AI 可以处理的步骤
- 怎样检查事实、数字和引用来源
- 什么时候不应该使用 AI
- 怎样避免上传敏感信息
- 怎样判断回答是否真的节省了时间

#### B. 工作流

从真实任务出发，展示完整输入、步骤、工具和输出。

- 长文 → 摘要 → 问题 → 待办
- 会议录音 → 纪要 → 责任人 → 截止时间
- 零散资料 → 大纲 → 初稿 → 复查
- 表格数据 → 清洗 → 分析 → 图表
- 主题 → 演示大纲 → PPT 初稿 → 人工调整
- 课程资料 → 知识点 → 问答卡 → 复习计划

#### C. 工具选择

不按品牌罗列，而是回答“完成这件事应该选哪个工具”。

- 查公开资料：ChatGPT / Perplexity / 搜索引擎
- 基于自己的资料提问：NotebookLM / 豆包
- 制作演示：Gamma / Canva / ChatPPT
- 处理表格：ChatExcel / ChatGPT
- 制作结构图：Whimsical / Diagramming AI
- 图片增强：Canva / Upscayl

### 4.1 分类筛选与映射

`ai-tool.indevs.in` 的工具质量和推荐标准不直接沿用，但它的分类能帮助我们覆盖真实任务。处理原则是：**保留分类价值，重新筛选工具；合并重复分类，删除与 AI 效率无关的分类。**

#### 分类使用原则

1. 分类用于资料库筛选，不直接放进一级导航。
2. 分类名称优先描述用户任务，不使用行业内部术语。
3. 同一个工具可以属于多个任务分类，但必须有一个主要分类。
4. 不因为某个分类下工具数量多就提高它的优先级。
5. 每个上线分类至少要有 3 个通过收录标准的工具，否则暂不展示。

#### 建议保留并合并

| 来源分类 | 拾用分类 | 处理方式 | 用户任务示例 |
|---|---|---|---|
| AI办公工具、办公效率 | 办公处理 | 合并 | 邮件、周报、会议、PPT |
| AI搜索引擎、AI搜索、搜索工具 | 搜索研究 | 合并 | 查资料、找来源、比较信息 |
| AI写作工具、内容创作 | 写作编辑 | 合并 | 大纲、初稿、改写、校对 |
| 科研文档、AI学习网站、研究习惯 | 学习与文档 | 合并 | 论文、课程、长文、复习 |
| AI设计工具、AI图像工具 | 设计与图像 | 合并 | 配图、海报、图片增强 |
| AI视频工具、智能剪辑、AI图像视频生成 | 视频制作 | 合并 | 生成视频、剪辑、字幕 |
| AI音频工具、AI音频 | 音频与语音 | 合并 | 语音输入、转写、配音 |
| AI提示指令 | 提示词模板 | 保留但改名 | 可复制的任务模板 |
| 信息管理、浏览器插件 | 信息管理 | 合并 | 收集、整理、稍后处理 |
| AI聊天助手、AI大模型平台 | 通用助手 | 合并 | 综合问答、写作、分析 |
| AI智能体 | 自动化 | 谨慎保留 | 多步骤任务、浏览器操作 |

#### 作为二期专题，不进入首版主分类

| 来源分类 | 原因 |
|---|---|
| AI编程工具、AI编程开发 | 有价值，但首版主要服务非开发者 |
| AI开发平台、云算力平台、AI训练模型 | 偏技术基础设施，不符合普通用户定位 |
| 电商运营工具、营销推广 | 场景较窄，后续可做“小团队运营”专题 |
| 爬虫 | 有效率价值，但存在部署门槛和平台规则问题 |
| AI内容检测 | 结果可靠性争议较大，需要单独解释限制 |
| AI课程 | 应作为内容或学习路径，不应和工具混为一类 |

#### 直接排除

- 免费赠送 VPN、账号服务、网盘资源
- 低价模型账号、卡密和不明 API 中转
- “免费用最高级大模型”等以额度套利为核心的分类
- 限时福利、职位推荐、创业资源和副业赚钱
- 量化数据、交易资源和投资社群
- 与效率任务无关的陪伴、角色扮演和生物骇客工具

#### 拾用首版资料库分类

最终不照搬 52 个来源分类，首版收敛为 9 个：

1. **通用助手**
2. **搜索研究**
3. **学习与文档**
4. **写作编辑**
5. **办公处理**
6. **表格数据**
7. **设计与图像**
8. **视频与音频**
9. **信息管理**

“提示词模板”属于内容类型，“自动化”先作为标签，暂不单独成为主分类。分类和标签只改变资料库结果，不跳转到新的栏目页。

## 5. 首页规格

首页必须在 20 秒内回答：这是什么、能帮我做什么、我现在从哪里开始。

### 首页区块

1. **Hero**
   - 标题：让 AI 真正帮你省时间
   - 说明：筛选实用方法、工作流和工具，把 AI 用进每天的学习与工作。
   - 搜索：输入任务，而不是只输入工具名。
   - 示例：整理会议、制作 PPT、总结长文、分析表格。

2. **两个核心入口**
   - 阅读本周总结
   - 搜索全部资料

3. **按任务筛选**
   - 处理文档
   - 整理会议
   - 写作与邮件
   - 表格与数据
   - 演示与设计
   - 学习与研究

4. **本周推荐方法**
   - 一篇完整、能立即执行的工作流。
   - 展示预计节省时间、使用工具、难度和隐私提醒。

5. **最新实用内容**
   - 4–6 张内容卡。
   - 每张卡显示任务场景、学习结果、阅读时间和难度。

6. **精选工具**
   - 首页最多展示 6 个。
   - 说明“适合什么任务”，不使用空泛的“最强 AI 工具”描述。

7. **第一次来**
   - 展示“小白入门”筛选结果，不创建独立学习路径页面。

## 6. 内容卡片规范

每张卡片至少包含：

- 任务场景
- 标题
- 看完能完成什么
- 阅读或操作时间
- 难度：小白 / 熟练
- 推荐工具
- 是否需要付费
- 隐私或准确性提醒
- 最近验证日期

禁止使用：

- “颠覆”“神器”“闭眼冲”“无限白嫖”等夸大文案
- 没有验证的免费额度和价格
- 只有产品功能列表、没有真实任务的方法
- 不说明局限性的工具推荐

## 7. 文章与工作流模板

### 方法文章

1. 你遇到的问题
2. 为什么普通提问不稳定
3. 一个可迁移的原则
4. 3–5 个操作步骤
5. 可复制模板
6. 错误示例与修改方式
7. 隐私、准确性或版权提醒
8. 今天可以尝试的一步

### 工作流文章

1. 任务目标
2. 输入材料
3. 使用工具
4. 完整步骤
5. 示例输入
6. 示例输出
7. 人工检查点
8. 预计耗时与节省时间
9. 适用与不适用场景

### 工具卡片

1. 它是什么
2. 最适合的一个任务
3. 不适合的任务
4. 免费版本能做什么
5. 最快上手步骤
6. 一个需要注意的问题
7. 官方入口
8. 最近验证日期

## 8. MVP 内容清单

建议首版完成 24–30 条高质量内容，不追求数量。

### AI 方法：6 条

1. 一个稳定的提问公式：背景 + 目标 + 约束 + 示例
2. 怎样把模糊任务拆成 AI 可以执行的步骤
3. AI 会胡说吗？检查答案的 5 个方法
4. 什么资料不应该上传给 AI
5. 让 AI 修改内容，而不是每次推倒重来
6. 怎样给 AI 一套明确的输出标准

### 办公工作流：8 条

1. 用 AI 把长 PDF 变成摘要、问题和待办
2. 会议录音转纪要、责任人和截止时间
3. 用 AI 写一封信息完整、语气自然的邮件
4. 从零散资料生成汇报大纲
5. 用 Gamma 或 Canva 制作 PPT 初稿
6. 用 ChatExcel 分析一张业务表格
7. 用 AI 比较多个方案并生成决策表
8. 把一周工作记录整理成周报

### 学习与研究：5 条

1. 用 NotebookLM 基于课程资料提问
2. 把一章教材变成知识点和问答卡
3. 查资料时怎样保留引用来源
4. 用 AI 制作一个可执行的学习计划
5. 用“先输出、再补知识”学习新领域

### 内容创作：5 条

1. 从主题到文章大纲的完整流程
2. 用 AI 找出初稿中的空话和重复内容
3. 用 Canva 快速制作内容配图
4. 把长内容改写成不同平台版本
5. 用 AI 整理选题，而不是批量生产低质量内容

### 工具比较：4 条

1. ChatGPT、Perplexity、NotebookLM 怎么选
2. Gamma、Canva、ChatPPT 怎么选
3. ChatExcel 和通用聊天 AI 怎么选
4. Whimsical、Diagramming AI 怎么选

- RecCloud：功能较多，需要和更专注的工具做比较。

## 10. 本周精选模板

每期只包含 5 个区块：

1. **一个值得知道的变化**：只解释对普通用户的实际影响。
2. **一个 AI 方法**：可迁移的使用原则。
3. **一个完整工作流**：真实任务的操作过程。
4. **一个工具**：适用场景、免费范围和限制。
5. **一个 5 分钟行动**：读者今天可以完成。

## 11. 搜索与筛选

### 搜索对象

- 任务：整理会议、写邮件、制作 PPT
- 工具：ChatGPT、Gamma、NotebookLM
- 输出：摘要、流程图、周报、复习卡

### 资料库筛选项

- 内容类型：方法 / 工作流 / 工具 / 对比汇总
- 主分类：通用助手 / 搜索研究 / 学习与文档 / 写作编辑 / 办公处理 / 表格数据 / 设计与图像 / 视频与音频 / 信息管理
- 任务标签：文档 / 会议 / 邮件 / 表格 / 演示 / 学习 / 图片 / 视频 / 音频
- 成本：免费 / 免费基础版 / 付费
- 难度：小白 / 熟练
- 平台：网页 / Windows / macOS / 移动端
- 数据方式：云端处理 / 本地处理

MVP 只实现关键词、内容类型、任务场景和成本筛选，其余可以后置。筛选结果始终停留在同一个资料库页面。

## 12. 成功指标

以下指标暂为方向指标，具体目标值待确认：

- 用户能够在 30 秒内说清网站是“帮助普通人用 AI 提效”。
- 用户能够在 2 分钟内找到一个对应当前任务的方法或工具。
- 内容页到工具页或工作流页的有效点击率。
- 工作流文章的阅读完成率。
- 用户点击“立即尝试”或复制模板的比例。
- 工具链接失效和信息过期率。

## 13. MVP 验收标准

- [ ] 一级导航只有首页、每周总结和资料库，不再出现投资及多余栏目页。
- [ ] 首页至少提供 6 个任务入口。
- [ ] 至少有 24 条完整内容，其中不少于 8 条工作流。
- [ ] 至少有 12 张符合模板的工具卡片。
- [ ] 每张工具卡包含官方链接和最近验证日期。
- [ ] 搜索支持按任务、工具名和描述匹配。
- [ ] 工具库至少支持场景和成本筛选。
- [ ] 资料库可以一键筛出小白入门内容，不单独创建学习路径页面。
- [ ] 所有方法文章都有可执行步骤和风险提醒。
- [ ] 手机端能够完整浏览导航、内容和工具卡片。

## 14. 分阶段计划

### Phase 1：方向切换

- 移除投资栏目与内容。
- 将现有 AI、投资和效率栏目收敛到统一资料库。
- 一级导航缩减为首页、每周总结和资料库。
- 调整首页定位、导航和搜索示例。
- 保留并重新分类现有 AI 工具。

### Phase 2：MVP 内容

- 完成 24–30 条首批内容。
- 建立工具卡片统一数据结构。
- 完成 AI 小白和办公提效两条入门路径。
- 完成一期本周精选。

### Phase 3：体验完善

- 增加场景与成本筛选。
- 增加工具对比页。
- 增加内容最近验证日期和过期提示。
- 根据实际使用数据调整首页入口。

## 15. 风险

| 风险 | 影响 | 应对方式 |
|---|---|---|
| 工具价格和免费额度变化快 | 推荐信息过期 | 记录最近验证日期，定期复查 |
| 网站重新变成工具导航站 | 缺少差异化 | 首页优先展示方法和工作流，工具只是执行层 |
| 内容过度依赖某个品牌 | 工具变化后内容失效 | 先讲方法，再讲具体工具 |
| AI 内容充满夸大宣传 | 损害信任 | 强制说明限制、风险和不适用场景 |
| 工作流看起来有用但无法复现 | 降低实际价值 | 每篇提供输入、步骤、输出和人工检查点 |
