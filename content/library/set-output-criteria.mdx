只说明“要做什么”，AI 会自行决定长度、结构和详细程度。加入验收标准，相当于提前告诉它你会怎样检查结果。

## 四类标准

1. **格式**：表格、清单、段落、字段或文件结构。
2. **范围**：长度、数量、时间、受众和必须覆盖的主题。
3. **证据**：哪些结论需要来源，哪些数字需要计算过程。
4. **禁区**：不能编造、不能省略、不能改变的内容。

<PromptBlock title="输出标准模板">
请完成：[任务]\n输出格式：[表格 / 清单 / 大纲]\n必须包含：[3—5 项]\n数量或长度：[限制]\n判断依据：[来源或已有材料]\n不得：[编造数据 / 改变事实 / 使用空泛表达]\n完成后请按以上标准自查，并单独列出仍不确定的地方。
</PromptBlock>

## 示例：会议待办

不要只说“整理会议纪要”，可以要求：

- 第一部分用 5 条以内概括结论。
- 第二部分输出待办表格，字段为任务、负责人、截止时间、依据原句。
- 没有负责人或日期时填写“待确认”。
- 不根据职位猜测负责人。

<Callout type="info" title="标准不要过多">
优先写会影响可用性的 3—6 条。标准太多、彼此冲突时，AI 同样难以稳定执行。
</Callout>
