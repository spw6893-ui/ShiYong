<ActionBox title="一句话结论">
快速找网页来源用 Perplexity；围绕一组 PDF 反复提问和生成学习产物用 NotebookLM；需要分析文件、写作或把网页与文件放进完整研究流程用 ChatGPT。
</ActionBox>

## 快速选择

| 任务 | 优先选择 | 原因 |
|---|---|---|
| 查一个近期事实 | Perplexity Search / ChatGPT Search | 都能快速返回网页来源 |
| 做多来源深度研究 | ChatGPT Deep research / Perplexity Deep Research | 会执行多轮检索并形成带来源报告 |
| 对多份 PDF 持续提问 | NotebookLM | 可选择来源并沿行内引用回到材料 |
| 从资料生成测验、闪卡、音频或 PPT | NotebookLM Studio | 产物类型最集中 |
| 分析 Excel、生成图表和检查计算 | ChatGPT 数据分析 | 可以查看代码、表格和图表 |
| 写邮件、周报和最终稿 | ChatGPT | 改写和多轮编辑更灵活 |

## 不要按品牌选择

先判断输入来自公开互联网还是自己的文件，再判断结果是“来源”“理解”“分析”还是“最终交付物”。同一任务可以串联工具，但不要在工具之间反复复制未经核查的摘要。

## 三条推荐路线

### 路线 A：公开资料 → 文章或汇报

Perplexity 找来源 → 人工打开关键网页 → ChatGPT 整理证据表和初稿 → Gamma 或 Canva 制作演示。

### 路线 B：多份 PDF → 学习或内部简报

NotebookLM 导入来源 → 沿引用提问 → Studio 生成报告、测验或 Slide Deck → 人工核对后导出。

### 路线 C：网页 + 上传文件 → 深度报告

ChatGPT Deep research 选择网页、文件或指定站点 → 审核研究计划 → 运行 → 检查引用 → 下载 Markdown、Word 或 PDF 报告。

<Callout type="info" title="功能正在重叠">
三者都在扩展搜索、文件和研究能力。选择重点不再是“能不能做”，而是来源控制、产物类型和后续编辑是否顺手。
</Callout>

<ToolCard name="Perplexity" href="https://www.perplexity.ai" label="打开官方入口">
适合先找公开资料。打开来源后仍需检查内容是否支持对应结论。
</ToolCard>

<ToolCard name="NotebookLM" href="https://notebooklm.google.com" label="打开官方入口">
适合围绕限定资料反复提问。不要上传公司机密和敏感个人信息。
</ToolCard>

<ToolCard name="ChatGPT" href="https://chatgpt.com" label="打开官方入口">
适合把资料转成大纲、邮件、计划和其他交付物。事实和数字需要人工复核。
</ToolCard>
