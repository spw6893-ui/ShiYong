## 最适合

在 Windows、macOS 或 Linux 本地放大低分辨率图片，并改善视觉清晰度。项目以开源桌面应用形式提供。

## 使用条件

官方项目说明桌面版依赖兼容 Vulkan 的 GPU，许多集成显卡可能无法正常运行。它适合像素化或分辨率不足的图片，不负责修复严重失焦。

## 为什么值得保留

图片处理可以在本机完成，适合不希望把普通工作图片上传到在线增强网站的场景。安装包应从官方网站或官方 GitHub Releases 获取。

## 注意

模型会估计和生成细节。放大不会恢复原图中不存在的真实信息，涉及证据或档案图片时不能把增强结果当作原始事实。
