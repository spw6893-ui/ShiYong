## 适合什么图片

- 尺寸太小、存在像素感的照片或插图。
- 需要批量放大的普通工作素材。
- 不希望把图片上传到在线增强网站的场景。

严重失焦、运动模糊或缺失的文字细节无法通过放大真实恢复。

## 当前使用步骤

<Steps>
### 第一步：从官方入口安装

从 Upscayl 官网或官方 GitHub Releases 下载。桌面版覆盖 Windows、macOS 和 Linux。

### 第二步：选择图片或 Batch Upscale

单张测试效果后，再对整个文件夹批量处理。大图和批量任务会明显增加显存与处理时间。

### 第三步：选择模型

照片先尝试通用或高保真模型；插画和动漫使用数字艺术方向模型。不要一次改变太多参数，便于比较。

### 第四步：选择倍率和输出目录

先使用 2x 或 4x。保留原文件并输出到新目录，不要覆盖唯一原图。

### 第五步：放大检查

在 100% 比例比较人脸、文字、边缘和纹理。出现过度锐化或假细节时换模型或降低倍率。
</Steps>

## 使用条件

官方项目说明桌面版依赖兼容 Vulkan 的 GPU，许多集成显卡可能无法正常运行。它适合像素化或分辨率不足的图片，不负责修复严重失焦。

<Callout type="warning" title="增强不等于还原">
模型会估计并生成细节。证据、档案、医学或科研图片不能把增强结果当作原始事实。
</Callout>
